# HardSubBot

بوت تيليجرام لدمج ترجمة SRT العربية داخل الفيديو باستخدام FFmpeg.

## المتطلبات
- Python 3.11 أو أحدث.
- FFmpeg وFFprobe مثبتان على بيئة التشغيل.
- Bot Token من BotFather.
- API_ID وAPI_HASH من https://my.telegram.org.
- حساب مساعد على Telegram.
- مجموعة عمل يضاف إليها البوت والحساب المساعد.

## الإعداد
1. انسخ `.env.example` إلى `.env` محليًا، أو أضف القيم نفسها إلى Replit Secrets.
2. املأ:
   - `BOT_TOKEN`
   - `API_ID`
   - `API_HASH`
   - `OWNER_ID`
   - `GROUP_ID` (معرّف مجموعة العمل؛ اتركه 0 للسماح بأي مجموعة، وهذا غير موصى به)
   - `WEBHOOK_URL` (رابط HTTPS كامل ينتهي بـ `/telegram/webhook`)
   - `WEBHOOK_SECRET` (قيمة عشوائية طويلة).
3. ثبّت الحزم: `pip install -r requirements.txt`.
4. ثبّت FFmpeg وFFprobe في بيئة Replit. تحقق بالأمرين `ffmpeg -version` و`ffprobe -version`.
5. شغّل: `python main.py`.
6. اجعل البوت والحساب المساعد عضوين في مجموعة العمل. امنح البوت صلاحية قراءة الرسائل وإرسالها، وعطّل Privacy Mode من BotFather إذا كان مطلوبًا أن يلتقط رسائل المجموعة العادية.
7. افتح الخاص مع البوت وأرسل `/start` ثم أضف الحساب المساعد.

## Webhook
يعمل Flask في الخيط الرئيسي، بينما يعمل PTB في خيط منفصل مع event loop مستقل. يستقبل Flask التحديثات على `/telegram/webhook` ويضيفها إلى `application.update_queue` باستخدام `call_soon_threadsafe`.

Webhook لا يجعل الاستضافة مجانية أو دائمة التشغيل تلقائيًا. استمرارية التشغيل تعتمد على نوع Replit Deployment وسياساته.

## الاستخدام
1. أرسل الفيديو إلى مجموعة العمل.
2. أرسل ملف `.srt` في رسالة منفصلة من المستخدم نفسه.
3. اضغط «بدء الدمج».
4. يتولى الحساب المساعد تنزيل الرسالتين، ثم يعالج FFmpeg الفيديو ويرفع الناتج إلى المجموعة.

## الخطوط العربية
ضع ملف خط عربي يدعم العربية داخل مجلد `fonts/`، وتأكد من تثبيته أو تعريفه في بيئة FFmpeg/Fontconfig. اضبط `SUBTITLE_FONT` باسم الخط الذي يتعرف عليه FFmpeg.

## حدود مهمة
- حد 2GB قيمة إعدادية فقط؛ يجب أن تسمح بها حدود Telegram والحساب والاستضافة والتخزين.
- إعادة تشغيل Replit قد توقف المهام الجارية؛ هذا الإصدار لا يستخدم قاعدة بيانات لاستعادة قائمة الانتظار بعد إعادة التشغيل.
- بيانات المهام الحالية في الذاكرة وتُفقد عند إعادة تشغيل العملية.
- تسجيل Telethon يتطلب إدخال رمز Telegram، وقد يتطلب كلمة مرور التحقق بخطوتين.
- لا تضع ملف `.session` أو أسرار البوت في GitHub.

## ملاحظات أمنية
استخدم مجموعة خاصة، واضبط `GROUP_ID`، ولا تشارك `WEBHOOK_SECRET` أو ملف جلسة الحساب المساعد.
